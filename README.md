# InsightAI — AI Survey Design & Analysis

A responsive, beginner-friendly web project that demonstrates the survey research process: question design, response collection, data visualization, and automated summary insights.

## Project objective
To understand people's awareness and use of Artificial Intelligence, including:
- Familiarity with AI
- Frequency of AI tool usage
- Popular AI tools
- Main purposes and perceived benefits
- Concerns about AI

## Features
- Responsive survey form with seven questions
- Multiple-choice and multi-select questions
- Live dashboard with four visual summaries
- Automatically generated insight summary
- CSV export for Excel or further analysis
- Browser-based response storage using `localStorage`
- Sample responses included for demonstration

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage
- CSV export

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Complete the survey and submit a response.
4. View the Analysis section and use **Export CSV** to download the data.

No installation or backend server is required.

## Deploy with GitHub Pages
1. Create a GitHub repository named `ai-survey-design-analysis`.
2. Upload all project files and folders from this project.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for the published website link to appear in the Pages section.

## Important notes about the data
This is a front-end academic demonstration. Responses are saved only in the current browser using `localStorage`; they are not sent to a central database and are not shared between visitors or devices. The initial dashboard uses clearly illustrative sample responses. Replace the sample dataset with real, ethically collected responses before making research claims. Do not collect names, contact details, or other sensitive personal information.

## Suggested project report
**Title:** AI Survey Design and Analysis  
**Aim:** To design an online survey and analyze public responses about Artificial Intelligence usage and awareness.  
**Methodology:** Prepare questions, collect anonymous responses, store the data in the browser, summarize response counts, visualize patterns, and export the dataset.
